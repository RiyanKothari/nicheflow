BACKEND:
- GET /api/settings — get all user settings
- PUT /api/settings/profile — update profile
- PUT /api/settings/workspace — update workspace config
- PUT /api/settings/notifications — update notification preferences
- PUT /api/settings/language — update language preference
- POST /api/settings/team/invite — send team invite
- DELETE /api/settings/team/:memberId — remove team member
- DELETE /api/settings/account — delete account with all data
- GET /api/settings/export/:type — export data as CSV
