Build the Client Management module at route "/clients". Use the authenticated layout.

HEADER:
- Page title using niche terminology (e.g. "Dogs & Owners" for dog trainer, "Clients" default)
- Stats row: Total clients, New this month, Active, Inactive
- Right: Search bar + Filter button + "+ Add Client" accent button

CLIENT LIST:
- Toggle between Table view and Card view
- Table columns: Avatar+Name, Phone, Email, Tags, Last Booking, Total Spent, Actions
- Card view: Profile cards in a grid — avatar, name, tags, total spent, last seen, quick action buttons
- Sort by: Name, Date Added, Total Spent, Last Visit
- Filter by: Tags (VIP, New, Inactive, Overdue), Date range
- Bulk select with checkbox — bulk tag, bulk export, bulk delete
- Clicking a client opens their full profile page

CLIENT PROFILE PAGE at "/clients/:id":
- Back button to client list
- Header: Large avatar (initials-based colored avatar), Name, Phone, Email, Tags
- Tag pills — VIP, New, Inactive, Overdue — click to add/remove
- Edit profile button
- Quick actions: "+ New Booking", "+ New Invoice", "WhatsApp" (opens wa.me link)

NICHE-SPECIFIC CUSTOM FIELDS section:
- Dog trainer: Dog's Name, Breed, Age, Vaccination Status, Behavioral Notes
- Tailor: Measurements (chest, waist, hip, length), Fabric Preferences, Style Notes  
- Farmer: Plot Size, Crop Type, Soil Type, Last Purchase
- Urban farmer / home repair / others: configurable custom fields
- Fields come from WorkspaceConfig terminology
- All fields editable inline

CLIENT HISTORY TIMELINE:
- Chronological list of all interactions
- Bookings — date, service, status, amount
- Invoices — invoice number, amount, status
- Notes — timestamped internal notes
- Each timeline item has an icon and color by type
- "Load more" pagination

NOTES SECTION:
- Internal notes — private, not visible to client
- Quick note input — type and press Enter
- Notes appear in timeline with timestamp
- Edit and delete individual notes

AI CLIENT INSIGHTS (card on profile):
- AI-generated summary: "Priya has been a client for 3 months. She books every Tuesday, has spent ₹12,000 total, and her last session was 5 days ago."
- At-risk flag: "This client hasn't booked in 30 days. Consider reaching out."
- Generate button — calls AI API with client's history data

ANALYTICS TAB on client list:
- Top 5 clients by revenue — bar chart
- Client retention rate — simple percentage with trend
- New vs returning ratio — donut chart using Recharts

BACKEND:
- GET /api/clients — all clients, with filters
- POST /api/clients — create client
- GET /api/clients/:id — full profile with history
- PUT /api/clients/:id — update client
- DELETE /api/clients/:id — soft delete
- POST /api/clients/:id/notes — add note
- All user-scoped, log to ActivityLog

Empty state: Friendly illustration + "No clients yet. Add your first one →"
