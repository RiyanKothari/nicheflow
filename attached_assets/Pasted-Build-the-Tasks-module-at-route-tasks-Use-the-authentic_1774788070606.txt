Build the Tasks module at route "/tasks". Use the authenticated layout. Use niche terminology from WorkspaceConfig.

HEADER:
- Page title from WorkspaceConfig (e.g. "Workflows", "Tasks", "To-Do")
- Stats row: Total tasks, Due today, Overdue (red), Completed this week
- Right: View toggle (List/Kanban/Calendar) + Filter + "+ New Task" button

KANBAN BOARD VIEW (default):
- 4 columns: To Do, In Progress, Done, On Hold
- Use niche-specific column names if set in WorkspaceConfig
  · Dog trainer: Upcoming, In Training, Completed, On Hold
  · Farmer: To Plant, Growing, Ready to Harvest, On Hold
- Task cards in each column:
  · Title, priority badge, due date, linked client (if any), assignee avatar
  · Color strip on left by priority: red (urgent), amber (high), blue (normal), gray (low)
- Drag and drop cards between columns using @dnd-kit/core
- Column card count badge
- "+ Add task" button at bottom of each column
- Smooth drag animation

LIST VIEW:
- Table: Title, Priority, Due Date, Status, Linked Client, Actions
- Priority badges color coded
- Overdue tasks highlighted in red
- Sortable columns
- Filter by priority, status, due date, linked client
- Search by task title
- Bulk complete, bulk delete

CALENDAR VIEW:
- Month calendar showing tasks by due date
- Click a day to see tasks due that day
- Color coded by priority

TASK DETAIL (slide-in panel):
- Title (editable inline)
- Description (rich text or textarea)
- Priority selector — Urgent, High, Normal, Low
- Due date + time
- Status selector
- Linked client — searchable dropdown
- Linked booking — searchable dropdown
- Subtasks:
  · Add subtask input
  · Each subtask has checkbox + title + delete
  · Progress bar showing X/Y subtasks completed
- Recurring toggle: None, Daily, Weekly, Monthly
- Comments/notes section — add internal notes
- Created date, last updated

AI FEATURES:
- Smart task suggestions: When a new booking is created, AI auto-suggests related tasks. "You have a session with Priya tomorrow. Add prep tasks?" — shows suggested tasks with one-click add
- Overdue flagging: AI surfaces overdue tasks in the dashboard next-best-action widget
- Natural language task creation via AI assistant: "Remind me to follow up with Manoj on Friday" → creates task automatically
- Weekly task summary: AI-generated summary shown on dashboard

QUICK ADD:
- Press "T" anywhere to open quick task input
- Type task title + Enter — creates task instantly with default priority and today's date
- Can expand to full form

FILTERS & VIEWS:
- My tasks (default for single-user, show all)
- Due today
- Overdue
- No due date
- By priority
- By linked client

BACKEND:
- GET /api/tasks — all tasks, filterable
- POST /api/tasks — create task
- PUT /api/tasks/:id — update task
- DELETE /api/tasks/:id — soft delete
- PATCH /api/tasks/:id/status — update status
- POST /api/tasks/:id/subtasks — add subtask
- PATCH /api/tasks/:id/subtasks/:subId — toggle subtask
- Recurring task generation — when a recurring task is completed, auto-create next occurrence
- Log to ActivityLog
